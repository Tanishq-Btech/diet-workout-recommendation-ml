# Diet & Workout Recommendation System

A machine learning–based web application that provides personalized diet and workout recommendations based on user health data and fitness goals.

---

## 🔍 Project Overview

Maintaining a healthy lifestyle requires proper diet and regular physical activity. However, most users lack personalized guidance that considers individual body parameters and health conditions. This project addresses that problem by offering customized diet and workout recommendations using machine learning techniques.

---

## ✨ Features

- User Login and Signup Authentication
- Personalized Diet and Workout Recommendations
- Machine Learning–based Similarity Matching
- Simple and User-Friendly Interface
- Secure User Data Handling
- Web-Based Application

---

## 🧠 Machine Learning Approach

- Data preprocessing using encoding and normalization
- Cosine Similarity algorithm for recommendation generation
- Personalized output based on user profile similarity

---

## 🛠️ Technologies Used

- **Frontend:** HTML, CSS  
- **Backend:** Flask (Python)  
- **Machine Learning:** Scikit-learn  
- **Database:** SQLite  
- **Deployment:** Render  
- **Version Control:** GitHub
